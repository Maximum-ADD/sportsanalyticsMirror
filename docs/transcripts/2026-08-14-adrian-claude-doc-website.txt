Auth: skip Firebase Auth entirely, use Auth.js (NextAuth) with the Google provider. This gets you "Sign in with Google" without touching the Firebase SDK at all — it's a plain OAuth flow through an established library, which is exactly the carve-out the brief gives for auth. DB: since you've used Azure, Azure Database for PostgreSQL (Flexible Server) is a reasonable pick — GitHub Student Developer Pack / Azure for Students gives you credits, and your familiarity cuts setup time. If nobody else on the team has Azure experience and it'd all fall on you, Neon (serverless Postgres, generous free tier, one connection string, zero ops) is the lower-friction default the rest of your team can actually work with independently. Worth asking the team: is this "whoever's fastest sets it up" or does everyone need to be able to touch the DB config without asking you?
