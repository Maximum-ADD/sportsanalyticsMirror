## Remaining Tasks

### 1. Deploy frontend to Cloudflare Pages
```powershell
cd apps/web
$env:VITE_API_BASE_URL="https://sportsanalytics-api.onrender.com"
npm run build
```
Upload `apps/web/dist/` to Cloudflare Pages (drag-and-drop or Wrangler CLI).

### 2. Set WEB_ORIGIN in Render
Once Cloudflare Pages gives you a URL (e.g. `https://<site>.pages.dev`), add it as `WEB_ORIGIN` in the Render Dashboard → Environment. This enables CORS for the cross-origin cookie flow.

### 3. Add production Google OAuth redirect URI
In Google Cloud Console → APIs & Services → Credentials → your OAuth client:
- Add `https://sportsanalytics-api.onrender.com/auth/callback/google` as an authorised redirect URI (alongside the existing `http://localhost:4000/auth/callback/google`).

## Key Decisions & Gotchas

- **Render free tier**: `NODE_ENV=production` is set as an env var, which makes `npm ci` skip devDependencies. The build command uses `npm ci --include=dev` to work around this.
- **tsconfig.json**: `"types": ["node"]` was added to `compilerOptions` so TypeScript recognises `process` and `console`.
- **Prisma migrations**: `preDeployCommand` is not supported on Render free tier. Migrations must be run manually with `npx prisma@5.22.0 migrate deploy` (pin the version — `npx prisma` downloads v7 which has breaking schema changes).
- **`.env` file**: Prisma reads from `.env` in `apps/api/`. If `DATABASE_URL` is set in both `.env` and the shell, `.env` takes precedence. The `.env` file is gitignored.
- **Gitea push mirror**: Configured in Gitea repo Settings → Mirror Settings. Uses GitHub PAT as the "password" in the Authorization section. "Sync when commits are pushed" is checked for instant mirroring.
